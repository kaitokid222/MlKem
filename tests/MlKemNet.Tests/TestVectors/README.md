# ACVP test vectors

No vectors are included in the initial scaffold.

When the ACVP tests are activated, copy `prompt.json` and
`expectedResults.json` only from a fixed release tag of NIST's
[ACVP-Server repository](https://github.com/usnistgov/ACVP-Server). Never use
the moving `master` branch as a test-vector source. Record the release tag and
file hashes in this file and in `docs/DESIGN_LOG.md`.
